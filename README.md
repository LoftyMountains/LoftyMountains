# 景行 Jingxing

> 高山仰止，景行行止。

景行是一款面向财经信息密集场景的实时市场工作台。它将多源财经快讯、沪深 300 分时行情、时间检索、同步回放和热点关联分析组织在同一张连续画布中，帮助用户从“发生了什么”快速进入“哪些主题、公司和市场正在相互影响”。

**在线体验：[www.loftymountains.com](https://www.loftymountains.com/)**

## 产品体验

### 实时市场

- 聚合财联社、华尔街见闻、金十数据、东方财富和新浪财经等主流财经来源。
- 对跨平台同标题快讯进行精确去重，保留来源、重要性和原文入口。
- 通过实时连接持续追加消息，并展示各信号源的在线状态与响应情况。
- 将快讯流与沪深 300 最近交易日分时行情并排呈现，便于对照新闻和指数变化。

### 时间查询与同步回放

- 按北京时间范围检索历史快讯。
- 在同一时间轴上同步回放消息与沪深 300 行情。
- 支持播放、暂停、拖动和 `1/2/5/10 分钟/秒` 历史时钟速率，并能随时返回实时市场。

### 热点与股票关联

- 提供 `1H`、`1D`、`1W`、`1M` 四个分析周期，并明确显示数据覆盖情况。
- 主题词云结合事件数量、突发度、来源多样性和舆情方向，突出更值得关注的财经信号。
- 关联图展示主题、股票及新闻共现、股票共现、公司行业、政策影响和供应链关系。
- 股票节点标注所属市场，并以红涨绿跌及颜色深浅表达当前周期涨跌幅。
- 悬停主题或股票即可查看相关快讯；选择股票后可继续查看关系证据和日 K 线。
- 词云、相关新闻与 K 线面板可独立折叠，让关联图按当前任务自动获得更多空间。

## 分析口径

景行不把词频直接等同于市场结论。热点得分综合事件规模、相对前窗变化、来源覆盖和信号方向；股票关系则结合共同事件数、NPMI、关系类型和置信度。界面保留证据快讯、统计周期和覆盖率，方便用户判断结论来自哪里、数据是否完整。

关联分析用于缩小信息范围，不构成事实核验或投资建议。行情与快讯可能因公开数据源、交易时段和网络状态而延迟。

## 项目边界

本仓库是景行的公开客户端，仅包含浏览器端界面、可视化与 GitHub Pages 发布工作流。聚合服务、分析任务、数据缓存、服务器配置和访问凭据不在本仓库中，也不会随静态网站发布。

景行展示的第三方快讯和行情归各数据提供方所有。使用、缓存或再分发相关数据时，应遵守对应平台条款和当地法规。
